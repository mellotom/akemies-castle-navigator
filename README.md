# akemies-castle-navigator

travelers guide for fortifying your sonic barriers: a one-page reference for **alm akemie's castle**, the dual four-operator fm vco built on a real yamaha opl3 chip. every control on the panel, the six algorithms drawn out, modulator vs carrier, the knob types, feedback, chords, the chip's quirks, patches and specs.

source: the alm011 operation manual.

not affiliated with alm busy circuits or yamaha.
